# OCR Module

## Overview
This module extracts text from documents using Tesseract OCR and Python.

## Requirements
- Python
- Tesseract OCR
- pytesseract
- Pillow
- PyMuPDF

## Installation

1. Install Tesseract OCR on your computer.
2. Install the Python dependencies:

   `ash
   pip install -r requirements.txt
   `

## Running the Scripts

Run the required Python script from the OCR_Module folder. For example:

`ash
python ocr_test.py
`

Note: Some scripts may require input document paths or Tesseract configuration to be updated for your computer.
